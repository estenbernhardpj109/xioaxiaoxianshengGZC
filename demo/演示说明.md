# 演示视频与复现

最终文件：演示视频.mp4，4分48秒，1280×912，25fps，H.264视频加AAC中文合成讲解，23个场景，不超过5分钟。字幕文本另附演示字幕.srt。

视频根据当前真实Web界面操作后采集的画面编排，属于操作快照加字幕的演示，不是连续实时录屏。业务参数、权限弹窗、余额、DAG与审计均来自实际本地沙箱，不从讲稿编造结果。讲解由本地Windows中文合成语音生成。全部金融及商户操作为模拟。

内容覆盖：多源数据全景、账单、500元确认转账、1001元强验证、理财比较与问卷、100元理财强验证、信用卡挂失、订阅续费和取消、生日预算预留与预约、注入拦截、审计。以evidence/video_validation.json为媒体规格记录。

## 可选重建

应用本体不需要以下媒体工具。重建需Node、Playwright、Python、FFmpeg，Windows中文讲解需System.Speech和Microsoft Huihui Desktop语音。

从参赛作品/demo安装可选开发依赖 `npm install`，然后运行 `node capture.mjs`。脚本启动独立8012沙箱，画面写入项目上一级 `.build/video`，不会操作真实银行。需安装Edge或把脚本的channel改成已安装的Chromium。

进入参赛作品的上一级目录运行：

```powershell
powershell -File 参赛作品/demo/narrate.ps1
$env:FFMPEG='你的ffmpeg可执行文件绝对路径'
python 参赛作品/demo/make_video.py
```

重新采集的模拟预约日期须晚于运行日。如果在2026-11-10以后复现，先修改示例生日为未来日期。合成语音与编码步骤只针对已经生成的UI画面；不要把未成功执行的画面称为实际业务完成。


## v3.0运营补充

最后40秒为带讲解的运营大屏开发阶段实际快照，描述MySQL、5秒刷新、工单与设备及脱敏。不是连续实时录屏，当前动态结果以本机页面为准。完整时长288.05秒。若重建：先按旧步骤生成248秒金融流程，再安装imageio-ffmpeg，运行demo/narrate_ops.ps1和demo/append_operations.py。不要对已包含尾段的288秒版本重复追加。
