# v4演示视频说明

当前MP4时长296秒（4分56秒），16个场景，H.264视频及AAC旁白，完整解码通过。视频画布1920×1200：上方120px为讲解标题，页面展示区域为1920×1080。原始浏览器位图因滚动条存在1920×1080和1905×1072两种尺寸，合成时等比例适配，不改变页面设计尺寸。

所有画面来自独立MySQL演示库的真实v4界面交互，采用截图配本机合成中文旁白及烧录字幕，不是连续录屏，也不是数字人浏览器语音的直接录音。注册成功、登录目标恢复、独立零余额账户、问答依据、待确认恢复、授权、图表、审计和运营入口均经检查。画面中的转账和生日预留请求随后取消，未演示扣款成功；真实执行及回滚由自动化用例验证。

金融、联系人、网点和设备数据均为模拟。本机主机和MySQL健康指标为实测。DeepSeek是可选接入，本次新版画面使用离线规则及本地知识问答；历史只读模型探测单独保留，不外推六场景在线效果。动效仅反馈请求状态，不宣称3D数字人或音素口型。

## 复现旁白和视频

先安装可选制作依赖imageio-ffmpeg==0.7.0（应用运行不需要），Windows需本机合法可用的Microsoft Huihui Desktop语音及微软雅黑字体。项目保存了16张原始截图、v4_scenes.json脚本和外置SRT字幕。

```powershell
.\demo\narrate_v4.ps1
python demo/build_video_v4.py
```

可设置FFMPEG指向已有的ffmpeg。制作缓存、波形和字体副本只写到项目外的.build/video-v4，不打包上传。脚本检查语音长度；超过300秒直接报错，不静默截断。demo/capture.mjs等旧版脚本保留作历史金融流程参考，当前提交视频由v4专用脚本生成。
