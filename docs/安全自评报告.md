# 安全自评报告

## 自评结论

知行已实现并验证赛题要求的权限分级、安全执行、审计与任务控制原型。系统适用于本机单账户模拟评审，尚不具备生产银行上线条件。已通过45项业务安全回归和15项HTTP集成检查。验证范围、未实现能力和残余风险如下，不以通过用例数替代安全性结论。

## 资产与信任边界

保护对象包括模拟余额、持仓、卡片状态、订阅协议、预约预算、定时任务与审计。外部输入来自用户自然语言、可选模型tool_calls及HTTP请求。模型输出始终是不可信提案。唯一可执行能力来自固定工具注册表，不包含shell、代码解释器、网络浏览或任意文件读写工具。

用户确认窗展示完整工具参数、操作详情和风险原因。强验证绑定当前会话、唯一步骤、参数摘要、一次性随机token和验证码，并检查180秒时效。旧步骤、旧token、取消后重放或其他浏览器会话均不应产生新的扣款。

## 权限与累计金额

|级别|操作|控制|
|---|---|---|
|绿色|余额、流水、账单、产品查询、模拟问卷等|自动执行并记录工具结果|
|黄色|累计≤1000元转账与定时转账、取消订阅、新卡申请、日限额调整等|展示全部参数并取得确认|
|红色|累计>1000元资金承诺、理财申购赎回、挂失补发、解冻|密码及模拟一次性验证码|

累计按北京时间自然日计算，计入已完成转账及当日新授权定时承诺，使用模拟汇率折人民币，确认时重新评估。已展示为红色的步骤不降级。生日后续预约只能引用当前DAG中已获授权的预留，不单独开放无预算预约。

三次强验证失败锁定模拟账户；单笔超过50000元或10分钟内已有五次资金承诺触发锁定。锁定后不会通过新建会话恢复写权限。生产的累计窗口、交易限额与解锁流程应由银行风险策略确定。

## 审计与恢复

审计使用SHA-256链接前一条记录，保留操作、风险、参数摘要、步骤依赖、执行成败与核验结果。密码和验证码不写入审计，收款人与备注在新执行记录中掩码处理。失败、取消、注入与人工接管也有事件。完整性测试验证单进程事件链，未提供外部可信锚、签名或WORM存储，攻击者若拥有审计文件写权限或数据库管理员权限仍可重算整条链。MySQL模式按自增序号恢复审计，支持相同时间戳，且业务状态、审计与运营请求同事务提交。

沙箱回退恢复账户与预约数据，但保留审计事件。若其他会话或定时任务改变状态，拒绝旧快照自动覆盖并暂停待人工处理。真实已结算转账不能用快照回退，须由银行侧实施有授权的冲正或补偿。

人工接管会按唯一审计来源生成MySQL复核工单和运营事件，经理可分派、处理、解决，但不会向外部客服发送消息。

## 凭据和数据声明

API密钥仅以进程环境或标准输入使用，未保存在源码、文档、前端或数据中，提交包排除.env及运行状态。演示金融数据为自建模拟集，不包含官方真实客户数据。账号、手机号和人物均是虚构测试标识，不可用于联系真实个人。团队仍需按实际参赛人员审核作品权属、AI辅助使用和隐私说明。


## MySQL、运营权限和脱敏补充

MySQL密码仅由环境变量或启动脚本隐藏输入；原始密码不进入提交包。SQL使用参数化值，数据库名通过标识符白名单。只操作本项目zx_表。银行写操作事务失败时恢复业务内存、会话、审计尾部和修订号；发生版本冲突时拒绝写入，不切换文件模式继续执行。

运营默认领导只读，经理口令独立于数据库和银行交易口令，由服务端绑定浏览器会话角色。5次口令错误锁定60秒，经理角色不跨浏览器继承，重启后清除。运营写操作要求CSRF及正确工单版本；不能通过body中的role字段提权。运营角色不扩展30项金融工具的授权。

大屏与导出只返回聚合及字段白名单；不包含客户姓名、手机号、账号、证件号、设备IP、原始对话、API密钥和确认token。内部客户查询表字段掩码，工单说明写入前处理已知姓名、手机号、长账号和密钥表达。完整沙箱JSON内部仍含虚构联系人匹配标识，不宣称全库加密或生产数据匿名化。

新增残余风险：本机经理口令文件依赖操作系统访问权限；root数据库账号权限过宽，生产需专用低权限账号和凭据管理；设备与请求演练数据不代表真实经营；当前只支持单业务实例，关系投影非高吞吐量账本；轮询快照可延迟5秒，数据库故障时保留旧快照并标记过期。旧JSON模式仅供独立回归，不提供运营大屏。

新增故障、角色、脱敏、设备工单及恢复测试见evidence/mysql_ops_results.json；检查项数以该记录为准。真实设备接入、生产IAM、TLS外部入口、银行级备份演练与外部审计锚仍未实现。
