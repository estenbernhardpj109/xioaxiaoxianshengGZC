# 银行界面配色与交互规范

本轮采用蓝白界面，将品牌主色、信息层级、业务状态与图表分类分别定义为可复用的设计变量。参考Ant Design企业产品色彩体系与WCAG文字对比度要求，不将设计参考表述为特定银行的监管认证。

## 颜色与用途

|角色|颜色|用途|
|---|---|---|
|主色|#165DCE|主要操作、当前导航、账户重点金额、键盘焦点|
|主色悬停|#104AA8|主要按钮悬停反馈|
|浅蓝底色|#EDF4FF|选中导航、次级强调|
|页面背景|#F4F7FC|与白色业务卡片分层|
|操作卡片|#FFFFFF|表单、对话、审批弹窗与图表|
|标题|#182B49|深色标题及重要信息|
|正文|#34445C|常规业务信息|
|辅助文字|#5F6F85|说明、时间、图表标签|
|成功|#167044|自动执行、在线、成功状态|
|确认|#8C5200|黄色权限、待确认风险提示|
|风险|#B42318|强验证标签、风险说明与高风险确认按钮|
|输入边界|#8292A8|输入框的可辨识边界|

品牌蓝不用作风险红的替代。高风险弹窗同时给出文字、颜色和操作详情；任务状态显示“已完成”“等待确认”等中文说明。数据分类图使用独立分类调色板，热力图使用浅蓝至深蓝的连续色阶。异常散点以红色三角与文字说明区分，避免仅依赖颜色。

## 可读性和交互

普通正文采用13至14px，辅助信息主要为11至12px，金额使用等宽数字布局。输入框、主按钮、次按钮及禁用状态分别定义，键盘操作有可见蓝色焦点，主要操作不使用低对比度浅色文字。

390px手机、820px平板及1440px桌面均检查横向溢出。手机端保留工作台、数据全景、执行审计导航，业务区域改为单列。

实测主按钮白字与蓝底对比度约6.02:1，辅助文字与白底约5.12:1，红色确认按钮约6.57:1；本轮检查的7组文字配色均超过4.5:1，输入边界与白底约3.17:1。这里只覆盖已列出的颜色组合，不构成整站WCAG符合性认证。

验证记录：evidence/ui_theme_validation.json，共19项检查通过，包括12个实际ECharts图表、风险弹窗、可见焦点、屏幕布局和关键配色。

## 实现与同步

CSS变量统一保存在frontend/style.css。图表主题frontend/theme.js读取同一套变量，dashboard.js与viz.js采用同一banking主题。

技术文档、安全自评、答辩PPT中的界面截图及248秒演示视频已更新为新版。应用数据、权限阈值与后端业务规则未改变。
