# 系统部署说明

## 环境与启动

系统运行只需要Python 3.10及以上和现代浏览器，后端全部使用标准库，ECharts离线依赖已随包提供。本轮验证平台为Windows与Edge，不宣称已验证其他操作系统。

解压提交包，进入 `参赛作品` 目录运行：

```powershell
python backend/server.py --port 8011
```

打开 http://127.0.0.1:8011 。服务只绑定127.0.0.1，拒绝其他Host值。网络隔离环境可运行规则模式。浏览器需要允许同源Cookie，API写操作要求 `X-Bank-CSRF` 请求头。

## 配置大模型

```powershell
$env:LLM_PROVIDER='deepseek'
$env:LLM_BASE_URL='https://api.deepseek.com/v1'
$env:LLM_MODEL='deepseek-flash'
$env:LLM_API_KEY=Read-Host 'API密钥'
python backend/server.py --port 8011
```

打开DeepSeek工具规划开关。服务端在调用时读取环境变量，默认离线模式不发送网络请求。代码不自动加载.env，示例配置不含密钥。可使用 `--api-key-stdin` 通过标准输入的一行传递密钥到服务进程内存，避免将密钥写入文件。

工具调用接口超时20秒，每次最多2048输出token，错误时回退规则引擎。`planner_source` 区分规则、模型或回退。模型生成的写操作必须匹配用户明确意图和已解析实体，且不能绕过独立授权。

2026-10-31查阅DeepSeek官方Tool Calls和Models文档后采用当前模型名。模型可用性随服务端变化，以环境变量覆盖。当前只保留一次真实只读调用的成功证据，不将其外推为全部在线场景验证。

## 状态与重置

默认状态文件为 `.runtime/bank.json`，审计文件为 `.runtime/audit.jsonl`。可以设置 `BANK_STATE_FILE`、`BANK_AUDIT_FILE` 到专门目录。状态采用临时文件原子替换，限单进程运行，不提供跨进程事务。

定时任务每5秒轮询，到期重新检查账户锁定和余额、卡片限制。强验证授权在创建定时任务时完成，执行失败不会静默再次扣款。任务完成状态持久化，避免正常重启后重复执行。崩溃在余额写入与持久化之间仍存在恢复风险，见自评。

演示重置：先停止服务，将 `.runtime` 改名备份后再启动。不要在服务运行中手工替换状态文件。会话和未确认计划仅在内存中，重启会清除；已有已授权定时任务仍保留。

如需推进生日演示时钟，先停止服务：

```powershell
python scripts/run_due.py --at '2026-11-08T12:00:00+08:00'
```

再重启查看订单状态。此命令只操作本地模拟数据，不是LLM工具，不会调用外部银行或商户。

## API与评审操作

|方法|路径|用途|
|---|---|---|
|GET|/api/health|运行状态、模型配置标记、浏览器CSRF值|
|GET|/api/tools|30项工具及函数调用Schema|
|GET|/api/dashboard|当前模拟账户的多表聚合与环境观测|
|GET|/api/audit|本地模拟审计|
|POST|/api/chat|text、session_id、mode|
|POST|/api/confirm|session_id、step_id、confirmed、password、otp、challenge_token|

先访问页面或health建立浏览器Cookie，再在同一浏览器请求写接口。会话ID不能被另一个浏览器复用。当前只有一个演示用户，共享同一沙箱账户，浏览器隔离不等价于多租户账户隔离。

## 测试与故障处理

```powershell
python tests/test_agent.py
python tests/test_http.py
python scripts/export_data.py
```

业务安全回归45项、HTTP集成15项，证据JSON位于evidence。测试HTTP服务使用临时状态目录和空闲端口，不修改现有演示账户。

端口占用时更换端口。DeepSeek开关禁用时检查服务进程是否有LLM_API_KEY。连续3次验证失败会锁定整个模拟账户，保留审计后按上述重置方式恢复；不提供聊天指令解锁。页面文字正常但图表不显示时确认本地vendor资源存在。发送处理中按钮禁用，避免并发重复提交。

## 部署边界

本轮不部署公网服务。标准库HTTP用于本机演示。生产接入需更换受审计的API网关、独立身份认证和真实MFA，银行适配器需实现事务、幂等和清算状态对账，商户适配器需具备库存及地址校验。不得直接将演示验证码或通用密码用于真实金融业务。
