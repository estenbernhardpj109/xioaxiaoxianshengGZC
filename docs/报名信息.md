## 三、项目简介（主选，与 `docs/作品简介.md` 完全一致，184 字）

知行面向银行业务构建可感知状态、规划任务并核验行动结果的数字智能体。系统以DeepSeek工具调用和离线规则双模式理解需求，通过DAG执行转账、账单分析、理财、卡片、订阅及生日预约。独立策略层落实累计金额分级、用户确认、模拟强验证、防重放及审计。多源数据全景以12种视图展示资金、消费、持仓与执行状态，支持中断、沙箱回退和人工接管。全部金融数据及银行商户操作均为模拟。

## 四、项目简介（备选，突出定位—能力—场景，362 字）

知行是面向手机银行的对话式 AI 智能体，把「翻菜单找功能」变成「说一句话办业务」。它以自然语言理解用户需求，生成带依赖关系的任务计划（DAG），再逐步调用固定银行工具执行；接入 DeepSeek 时由模型通过 Function Calling 选择工具与参数，模型输出仅视为提案，无密钥或调用异常时自动回退离线规则引擎。覆盖智能转账、账单分析、理财操作、卡片管理、订阅代扣、生日联动六个方向。安全上设独立策略层：按当日累计金额分级（自动执行 / 用户确认 / 密码加强验证），并具备防重放、一次性验证码、注入防护、异常拦截、哈希串联审计，支持中断、沙箱回退与人工接管。结果以 12 种视图呈现资金、消费、持仓与执行状态。应用场景：手机银行 App、微信银行与企微客服、远程坐席辅助、适老化服务。全部数据与银行操作均为模拟。
